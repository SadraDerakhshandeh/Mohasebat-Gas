# وب‌اپ مهندس گاز

این نسخه یک وب‌اپ مستقل، فارسی و RTL است و بدون نصب یا سرور قابل اجراست.

## اجرا
فایل `index.html` را مستقیماً با مرورگر باز کنید.

## ماژول‌ها
- محاسبه دریچه تأمین هوا: منطق و فرمول‌های Sheet «محاسبه دریچه تامین هوا»
- سایزینگ لوله گاز: جدول کامل ظرفیت‌های Sheet «سایزینگ لوله» و منطق VLOOKUP تقریبی
- انتخاب دستگاه گازسوز: ماتریس Sheet «انتخاب دستگاه گاز سوز»
- تبدیل واحدهای مهندسی: طول، مساحت، حجم، دبی، فشار، دما، توان/انرژی و قطر لوله
- اعتبارسنجی: نمونه‌های مرجع منطق محاسباتی

## نکته سایزینگ لوله
در منطق محاسباتی از VLOOKUP تقریبی استفاده شده است؛ بنابراین برای فاصله‌ای که دقیقاً در جدول نیست، نزدیک‌ترین طول پایین‌تر جدول مبنا قرار می‌گیرد. در وب‌اپ نیز همین منطق پیاده شده است.
